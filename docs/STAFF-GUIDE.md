# Shopify Staff Guide

1. Manage products, variants, pricing, inventory, collections, menus, pages and articles in Shopify Admin.
2. Keep the product title and variant option names `Material Type` and `Size` for live material and size selection.
3. Add correction-ready copy to Shopify only; this storefront reports known content issues in generated content audits rather than hard-coding them.
4. Use Shopify Metaobjects for home sections, announcements, materials, FAQs, reviews and lookbook scenes once their storefront definitions are configured.
5. Create draft orders for custom table quotes through the server-only Admin API integration; never expose the Admin token in the browser.
