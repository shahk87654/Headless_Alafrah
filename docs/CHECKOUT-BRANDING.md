# Shopify checkout branding

Enter these values in the Shopify checkout editor:

- Background: `#F1F2EF` (Calacatta)
- Accent / links: `#2D4A3E` (Jungle)
- Primary button: `#2D4A3E` (Jungle)
- Text: `#16181B` (Marquina)
- Error / sale colour: `#C4873A` (Onyx Amber)
- Secondary surface: `#D8CCB5` (Travertine)
- Corner radius: 6px
- Heading font: Italiana, or the closest available inscriptional serif
- Body font: Instrument Sans, or the closest available geometric sans

Upload the Al Afrah Technical logo and keep the storefront footer wordmark separate from checkout.
